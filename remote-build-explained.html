🧹 Cleanup guarantee (even on failure)

temporary branch  → delete  (gh api DELETE refs/heads/...)
workflow run      → delete  (gh run delete <id>)
local .tar.gz     → delete
temp clone dir    → delete

Every build gets remote-build-<timestamp>-<rand>. try/finally + Ctrl+C → gh run cancel then cleanup. Never touches main/master.

🚀 Setup (2 minutes)

1️⃣ Build repo (once)

gh repo create OWNER/remote-rust-build --public
# add .github/workflows/build.yml + README.md
git push -u origin main

2️⃣ Any project

export REMOTE_BUILD_REPO=OWNER/remote-rust-build
gh auth login
cp /path/to/remote_build.py ./my-app/
cd my-app && python remote_build.py
Throwaway branches & artifacts only • main/master never modified • no releases, PRs, issues, or permanent tags
